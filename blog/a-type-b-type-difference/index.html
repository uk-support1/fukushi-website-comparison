就労継続支援A型とB型の違いとは？対象者・給与（工賃）・働き方を比較表で解説

公開日 2026年11月8日 読了目安 約4分 執筆・編集 福祉ホームページ制作比較ガイド編集部

「A型とB型は何が違うの？」は、利用を検討するご本人・ご家族から最も多く寄せられる質問のひとつです。事業所としても、違いを正しく説明できることは信頼につながります。この記事では、両者の違いを比較表で整理します。

この記事でわかること

  • A型とB型の最大の違いは「雇用契約の有無」
  • 対象者・賃金（工賃）・年齢・利用期間の違い
  • 就労移行支援・就労選択支援との関係
  • 事業所ホームページで違いを伝えるときの注意点

A型とB型の違いを一言でいうと

就労継続支援A型とB型は、どちらも「一般企業で働くことが難しい障害のある方に、働く場と訓練の機会を提供する」サービスです。最大の違いは、事業所と利用者が雇用契約を結ぶかどうかです。

  • A型（雇用型）：事業所と雇用契約を結び、労働者として働く。最低賃金以上の給与が支払われる
  • B型（非雇用型）：雇用契約を結ばず、体調やペースに合わせて作業する。生産活動の成果に応じた「工賃」が支払われる

平均賃金・平均工賃の目安

厚生労働省の調査では、A型の平均賃金は月額8万円台、B型の平均工賃は月額2万円台で推移しています（年度により変動します）。B型の工賃は事業所の生産活動の内容によって大きく差があり、平均工賃は基本報酬の区分にも関係します。2026年度の臨時報酬改定では、平均工賃の上昇を踏まえて基本報酬区分の基準額が見直されています。

B型を利用するまでの流れと就労選択支援

B型を新たに利用する場合、これまでは就労移行支援事業所などによる「就労アセスメント」を経るのが一般的でした。2025年10月からは、新たにB型を利用する方は原則として「就労選択支援」を利用する仕組みに変わっています。

ただし、次のような方は就労選択支援を経ずにB型を利用できる場合があります（本人が希望すれば利用することも可能）。

  • 就労経験があり、年齢や体力の面で一般企業に雇用されることが困難になった方
  • 50歳に達している方
  • 障害基礎年金1級を受給している方

A型・就労移行支援についても、2027年4月から就労選択支援の原則利用が予定されています。制度の詳しい運用は自治体によって案内が異なる場合があるため、市町村の窓口で確認しましょう。

就労移行支援との違い

就労移行支援は、一般企業への就職を目指す方が、原則2年間の標準利用期間の中で職業訓練や就職活動の支援を受けるサービスです。働く場そのものを提供するA型・B型とは目的が異なります。

サービス目的収入利用期間
就労移行支援一般就労に向けた訓練・就職活動原則なし原則2年
就労継続支援A型雇用契約にもとづく就労の場給与定めなし
就労継続支援B型自分のペースでの就労の場工賃定めなし

事業所のホームページで伝えたいこと

A型・B型の事業所を探している方は、「どんな作業があるか」「どのくらい通えばいいか」「いくらもらえるか」を特に気にしています。ホームページでは次の情報を具体的に載せると、見学・問い合わせにつながりやすくなります。

  1. 作業内容：軽作業、農作業、カフェ・飲食、パソコン作業など。写真があるとイメージしやすい
  2. 利用日数・時間の目安：「週2日・1日2時間から相談可」など、始めやすさを伝える
  3. 工賃・給与の実績：B型の場合は前年度の平均工賃、A型の場合は時給と勤務時間の目安
  4. 送迎・昼食の有無：通いやすさに直結する情報
  5. 見学・体験の流れ：問い合わせから利用開始までのステップを図や番号付きで説明

工賃・給与の表記は正確に

平均工賃や給与を掲載する場合は、「令和7年度実績」のように時点を明記し、実績と異なる金額を書かないよう注意しましょう。誇張した表現は、利用者とのトラブルや行政指導の原因になります。

B型事業所のホームページ制作を検討している場合は、就労継続支援B型向けホームページ制作会社の比較記事も参考にしてください。

まとめ

A型とB型の違いは「雇用契約の有無」が基本です。A型は最低賃金以上の給与を得て働く雇用型、B型は自分のペースで工賃を得ながら作業する非雇用型です。2025年10月からはB型の利用にあたって就労選択支援が原則となるなど、仕組みも変わりつつあります。

事業所としては、こうした違いをホームページでわかりやすく説明し、作業内容や通い方、工賃の実績などを具体的に伝えることが、利用者に選ばれる第一歩になります。

よくある質問

A型とB型を同時に利用することはできますか？

一般的には、同じ時間帯にA型とB型を併用することはできません。ただし、市町村が必要と認めた場合に異なるサービスを組み合わせる例もあるため、詳しくは市町村の障害福祉担当窓口に確認してください。

B型からA型や一般就労へステップアップできますか？

可能です。B型で生活リズムや作業に慣れたあと、A型や就労移行支援、一般企業への就職へ進む方もいます。事業所のホームページで「卒業生の進路実績」を紹介すると、利用を検討する方の参考になります（個人が特定されないよう配慮が必要です）。

A型の利用に年齢制限はありますか？

A型は雇用契約を結ぶため、原則として利用開始時に65歳未満の方が対象です。65歳以上の方は、65歳になる前から引き続き利用している場合など、一定の条件で利用できることがあります。B型には年齢の上限はありません。
