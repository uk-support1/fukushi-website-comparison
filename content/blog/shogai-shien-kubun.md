## 障害支援区分とは

障害支援区分は、障害の特性や心身の状態に応じて、**必要とされる標準的な支援の度合い**を総合的に示すものです。障害者総合支援法にもとづき、市町村が認定します。

区分は「非該当」と「区分1〜区分6」に分かれ、数字が大きいほど必要な支援の度合いが高いことを示します。2014年4月に、それまでの「障害程度区分」から現在の「障害支援区分」に改められ、知的障害や精神障害、発達障害の特性がより反映されるようになりました。

## 区分によって利用できるサービスの例

障害支援区分は、主に介護給付のサービスを利用するときに必要です。サービスによって、対象となる区分が決まっています。

| サービス | 対象となる区分の例 |
| --- | --- |
| 居宅介護、短期入所 | 区分1以上 |
| 生活介護（通所） | 区分3以上（50歳以上は区分2以上） |
| 行動援護 | 区分3以上＋行動関連項目の条件 |
| 施設入所支援 | 区分4以上（50歳以上は区分3以上） |
| 重度訪問介護 | 区分4以上＋状態の条件 |
| 療養介護 | 区分5以上または区分6（疾患・状態による） |
| 重度障害者等包括支援 | 区分6＋状態の条件 |

区分は、利用できるサービスの種類だけでなく、事業所が受け取る報酬の単価や、1か月に利用できるサービスの量（支給量）の目安にも関わります。

## 認定調査80項目の内容

障害支援区分の判定は、市町村の認定調査員などが本人と面談して行う**80項目の認定調査**から始まります。

| 分野 | 項目数 | 主な内容 |
| --- | --- | --- |
| 移動や動作等に関連する項目 | 12項目 | 寝返り、起き上がり、立ち上がり、歩行、移乗など |
| 身の回りの世話や日常生活等に関連する項目 | 16項目 | 食事、入浴、排せつ、薬の管理、金銭の管理、調理、買い物など |
| 意思疎通等に関連する項目 | 6項目 | 視力、聴力、コミュニケーション、説明の理解など |
| 行動障害に関連する項目 | 34項目 | 被害的・拒否的、昼夜逆転、大声、こだわり、多動、自傷など |
| 特別な医療に関連する項目 | 12項目 | 点滴、透析、たんの吸引、経管栄養など |

このほか、調査票には、項目では表しきれない本人の状態を記載する「特記事項」があります。

## 判定から認定までの流れ

1. **申請**：本人または家族が市町村に申請する
2. **認定調査**：調査員が自宅などで本人・家族と面談し、80項目を調査する
3. **医師意見書**：市町村が主治医に意見書の作成を依頼する
4. **一次判定**：調査結果と医師意見書の一部の項目をもとに、コンピュータで判定する
5. **二次判定**：市町村の審査会（医療・福祉の専門家で構成）が、一次判定の結果、特記事項、医師意見書をもとに審査・判定する
6. **認定・通知**：市町村が区分を認定し、本人に通知する

## 有効期間

障害支援区分の有効期間は、原則として**3年**です。状態が変わりやすい場合などは、3か月〜3年の範囲で短く設定されることがあります。有効期間が終わる前に更新の申請が必要です。

また、病気の進行や生活環境の変化などで状態が変わった場合は、有効期間の途中でも区分の変更を申請できます。

## 認定調査を受けるときのポイント

認定調査は、本人の実際の生活の様子を正確に伝えることが大切です。

1. **「できる日」ではなく「普段の様子」を伝える**：調査の日だけ調子がよい、緊張して普段と違う行動をとる、ということはよくあります
2. **困りごとのメモを用意する**：夜間の様子、パニックの頻度、外出時の困りごとなど、家族や支援者が気づいていることを書き出しておく
3. **家族や支援者が同席する**：本人だけでは伝えきれないことを補足してもらう
4. **主治医に生活の様子を伝えておく**：医師意見書に日常生活の状況が反映されるよう、受診時に伝えておく

:::point 行動障害は特に伝わりにくい
知的障害や精神障害、発達障害の方の行動上の困難は、短時間の面談では見えにくいことがあります。どのくらいの頻度で、どのような場面で、どの程度の支援が必要かを具体的に伝えましょう。
:::

## まとめ

障害支援区分は、必要な支援の度合いを区分1〜6の6段階で示すもので、介護給付のサービスを利用するときに必要です。80項目の認定調査と医師意見書をもとに、コンピュータによる一次判定と審査会による二次判定を経て認定され、有効期間は原則3年です。

調査では普段の生活の様子を具体的に伝えることが、本人に合った支援につながります。受給者証の申請の流れは「[障害福祉サービス受給者証の取り方](/blog/jukyushasho/)」で解説しています。
