## Googleビジネスプロフィールとは

Googleビジネスプロフィールは、Google検索やGoogleマップに表示される事業所の情報（名称、住所、電話番号、営業時間、写真、口コミなど）を、事業者自身が登録・管理できる無料のサービスです。

利用者や家族、相談支援専門員がスマートフォンで事業所を探すとき、多くの場合はまず地図の検索結果を見ます。ここで事業所の情報が正しく、魅力的に表示されていれば、ホームページへの訪問や電話での問い合わせにつながります。

:::info すでに登録されていることも
Googleマップには、事業者が登録していなくても、利用者の情報提供などで事業所が掲載されていることがあります。その場合は、事業者として「オーナー確認」を行うことで、情報を管理できるようになります。古い営業時間や誤った電話番号が表示されていないか、一度確認してみましょう。
:::

## 登録の流れ

1. Googleアカウント（事業所用のものがおすすめ）でGoogleビジネスプロフィールにアクセスする
2. 事業所名を検索し、すでに掲載がある場合はオーナー確認を申請、ない場合は新規に登録する
3. 業種（カテゴリ）、住所、電話番号、ホームページのアドレスなどを入力する
4. Googleの指示に従って、オーナー確認（動画撮影、電話、メール、はがきなど）を行う
5. 確認が完了したら、営業時間や写真などの情報を充実させる

:::warn 事業所用のアカウントで管理する
職員個人のGoogleアカウントで登録すると、その職員が退職したときに管理できなくなるおそれがあります。事業所（法人）で管理するアカウントで登録し、複数の職員を「管理者」として追加しておきましょう。
:::

## 設定しておきたい項目

| 項目 | ポイント |
| --- | --- |
| ビジネス名 | 看板や指定を受けている正式な名称と同じにする。地域名やキーワードを付け足さない |
| カテゴリ | 「障害者支援施設」「デイケアセンター」など、もっとも近いものをメインに選ぶ |
| 住所・サービス提供地域 | 通所型は住所を表示。訪問型は提供地域を設定 |
| 営業時間 | 祝日や年末年始の特別営業時間も設定する |
| 電話番号 | 問い合わせを受ける代表番号 |
| ウェブサイト | 自社ホームページのアドレス |
| ビジネスの説明 | サービスの種類、対象者、特色を簡潔に。誇張しない |
| 属性 | 車いす対応の入口、駐車場などバリアフリー情報 |

:::point ビジネス名にキーワードを詰め込まない
「◯◯市で人気No.1の放課後等デイサービス◯◯」のように、正式名称にない言葉をビジネス名に加えるのはGoogleのガイドライン違反です。表示が停止されるおそれがあるため、正式名称で登録しましょう。
:::

## 写真・投稿・口コミの活用

### 写真

外観、入口、活動スペース、作業の様子、送迎車などの写真を掲載すると、初めて訪れる人が場所や雰囲気をイメージしやすくなります。**外観と入口の写真**は、見学に来る人が迷わないためにも特に重要です。

### 投稿（最新情報）

イベントのお知らせ、見学会の案内、空き状況、休業日のお知らせなどを投稿できます。ホームページのお知らせと連動させて、定期的に更新しましょう。

### 口コミへの返信

口コミには、事業者として返信できます。好意的な口コミにはお礼を、改善を求める口コミには事実を確認したうえで誠実に返信しましょう。

:::warn 口コミの返信では個人情報に触れない
返信の中で「◯◯様の件では」「先日の送迎の際に」など、利用者が特定される内容を書くことは避けましょう。口コミを書いた人が利用者本人や家族であることを、事業所側から認めることにもなりかねません。「貴重なご意見をありがとうございます。ご指摘の点は職員で共有し、改善に努めます」など、一般的な表現にとどめます。
:::

また、口コミを書いてもらう見返りに特典を提供する、職員や関係者に口コミを書かせるといった行為は、Googleのポリシーで禁止されています。

## 福祉事業所ならではの注意点

- **利用者が写る写真は同意を得てから**：オーナー以外のユーザーが投稿した写真に利用者が写っている場合は、削除の報告も検討する
- **グループホームの住所の扱い**：生活の場であるため、住所を表示するかどうかは慎重に判断する
- **複数事業所の登録**：同じ建物に複数のサービスがある場合、それぞれの扱いはGoogleのガイドラインを確認する
- **営業電話に注意**：「Googleの担当者」を名乗る有料の代行営業や、上位表示を保証する営業には注意する

## まとめ

Googleビジネスプロフィールは、地図検索で事業所を見つけてもらうための無料のツールです。正式名称、カテゴリ、営業時間、写真などの情報を正確に整え、投稿や口コミへの返信を続けることで、見学や問い合わせのきっかけを増やせます。

ホームページとGoogleビジネスプロフィールの情報を一致させることも大切です。地域での検索対策の全体像は「[福祉事業所のホームページを地域検索で見つけてもらうSEOの基本](/blog/local-seo-basics/)」で解説しています。
