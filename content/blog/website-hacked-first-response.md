## こんなサインがあったら改ざんを疑う

次のような症状がひとつでもあれば、改ざんや乗っ取りの可能性があります。

- ホームページを開くと、見覚えのない別のサイト（通販サイト、懸賞、警告画面など）に移動する
- Googleの検索結果に、事業所名とともに不審な日本語や商品名が表示される
- 検索結果に「このサイトはハッキングされている可能性があります」と表示される
- ブラウザやセキュリティソフトが「危険なサイト」と警告する
- サーバー会社から「不正なファイルを検知した」「迷惑メールを大量送信している」と連絡が来る
- WordPressの管理画面に、知らない管理者ユーザーが追加されている
- 管理画面にログインできなくなった

:::info 自分では気づきにくいことも
改ざんの中には、スマートフォンから検索経由でアクセスしたときだけ不正なサイトに移動するなど、管理者が普段見ている画面では気づけないものもあります。利用者や家族、取引先から「ホームページがおかしい」と言われたら、軽視せずに確認しましょう。
:::

## 最初の1時間でやること

### 1. 落ち着いて記録を残す

いつ、誰が、どの画面で、どんな症状に気づいたかを記録します。画面のスクリーンショットを撮り、表示されたURLも控えておきましょう。後の調査や報告で必要になります。

### 2. 被害の拡大を止める

閲覧者への被害を防ぐため、ホームページの公開を一時的に止めます。具体的な方法は環境によって異なるため、制作会社やサーバー会社の指示に従ってください。サーバー会社の管理画面からサイトを一時停止できる場合もあります。

### 3. 関係者に連絡する

- **制作会社・保守会社**：調査と復旧を依頼する
- **サーバー会社**：不正アクセスの記録（ログ）の確認、サーバー側の対応を依頼する
- **法人内の責任者**：管理者・理事長などへ報告し、対応の判断を仰ぐ

### 4. パスワードを変更する

ホームページの管理画面だけでなく、サーバー、FTP、データベース、ドメイン管理、関連するメールアカウントのパスワードを変更します。ウイルスに感染している可能性がある端末からは変更しないようにしましょう。

:::warn やってはいけないこと
- 改ざんされたファイルを、記録を残さずにすぐ削除・上書きする
- 原因がわからないまま、バックアップから復元してそのまま公開を再開する
- 「被害はありません」と根拠なく公表する
- 一人で抱え込み、法人内の責任者に報告しない
:::

## 個人情報が漏えいした可能性がある場合

問い合わせフォームや見学申込みフォームを設置している場合、入力された情報が盗まれた可能性も考えなければなりません。

個人情報保護法では、次のような場合に**個人情報保護委員会への報告と本人への通知**が義務付けられています。

- **要配慮個人情報**（病歴、障害の有無など）が含まれる個人データの漏えい等（そのおそれを含む）が発生した場合
- **不正アクセスなど不正の目的**による漏えい等（そのおそれを含む）が発生した場合
- 財産的被害が生じるおそれがある場合
- 1,000人を超える漏えい等が発生した場合

報告は、事態を知ってから**速やかに（おおむね3〜5日以内）速報**を、原則として**30日以内（不正の目的による場合は60日以内）に確報**を行います。福祉事業所の場合、問い合わせの内容に障害や病気に関する情報が含まれることが多いため、対象になる可能性が高いと考えておきましょう。

:::check フォームから送信される情報も対象に
2024年4月の個人情報保護法施行規則の改正により、ホームページのフォームに入力されて送信される途中の情報など、事業者が「取得しようとしている」個人情報が不正アクセスで盗まれた場合も、報告の対象に含まれることが明確になりました。フォームを設置している事業所は特に注意が必要です。
:::

あわせて、指定権者である都道府県・市町村の障害福祉担当課にも連絡し、必要な対応を確認しましょう。被害の内容によっては、警察への相談も検討します。

## 復旧と再発防止

### 原因を調べてから復旧する

改ざんの原因（侵入経路）を特定しないまま元に戻すと、同じ方法で再び攻撃される可能性があります。制作会社や専門家に、次のような点を調査してもらいましょう。

- どのファイル・ページが改ざんされたか
- 古いソフトウェアやプラグインの脆弱性が使われたか
- 不正なログインがあったか、いつからか
- 不正なファイル（バックドア）が残っていないか

### 安全なバックアップから復元する

改ざんされる前の時点のバックアップから復元し、WordPress本体やプラグインを最新版に更新したうえで公開を再開します。Googleの検索結果に警告が出ている場合は、Search Consoleから再審査をリクエストします。

### 再発防止策を実施する

- ソフトウェアの更新体制を見直す（自動更新、保守契約）
- 不要なプラグイン・アカウントを削除する
- 二段階認証を設定する
- 定期的なバックアップと復元テストを行う

具体的な対策は「[WordPressセキュリティ対策チェックリスト](/blog/wordpress-security-checklist/)」を参考にしてください。

## 事前に準備しておきたい連絡先リスト

いざというときに慌てないよう、次の連絡先を一覧にして、紙でも保管しておきましょう。

| 連絡先 | 用途 | 記入例 |
| --- | --- | --- |
| 制作会社・保守会社 | 調査・復旧の依頼 | 会社名、担当者、電話番号、受付時間 |
| サーバー会社 | ログ確認・サイト停止 | 契約ID、サポート窓口 |
| ドメイン管理会社 | ドメインの乗っ取り対応 | 契約ID、サポート窓口 |
| 法人内の責任者 | 対応の判断・公表の決定 | 氏名、連絡先 |
| 指定権者（自治体） | 事故報告・相談 | 障害福祉担当課の電話番号 |
| 個人情報保護委員会 | 漏えい等の報告 | 委員会ホームページの報告フォーム |
| 都道府県警察 | サイバー犯罪の相談 | サイバー犯罪相談窓口 |
| IPA・JPCERT/CC | 技術的な相談・報告 | 各窓口のホームページ |

## まとめ

ホームページの改ざんに気づいたら、まず記録を残し、公開を止めて被害の拡大を防ぎ、関係者に連絡することが大切です。個人情報の漏えいのおそれがある場合は、個人情報保護委員会への報告と本人への通知が必要になることがあります。

原因を調べずに元に戻すと再び被害にあうおそれがあります。日頃から連絡先リストとバックアップを用意し、「何かあったら誰に連絡するか」を決めておくことが、最大の備えになります。
